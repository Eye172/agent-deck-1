INSIDE AGENT DECK

Small cartridges.
Clear contracts.

Explore 64 architecture families and 384 application presets, spanning basic workflows through expert systems.

  1. Find a fit. Search by mechanism, application or complexity. The same family has six task-specific adaptations.
  2. Inspect the wiring. Follow colored agent roles, tools, memory and conditional transitions. Select a node to inspect its contract, then check budgets and failure modes.
  3. Make it yours. Download a JSON blueprint or Markdown guide. Implement the model and tool adapters in your preferred runtime.
  4. Measure it. Use the fixture and acceptance criteria. Compare against a direct-call baseline before adding complexity.

Blueprints are design specifications, not executable agents or drop-in framework configurations. No account, API key or telemetry is required to browse.
